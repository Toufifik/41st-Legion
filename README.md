# Escouade Omega — thème vert

Site statique prêt pour GitHub Pages.

## Mise en ligne

1. Crée un dépôt GitHub (par exemple `escouade-omega`).
2. Envoie **tout le contenu de ce dossier** dans le dépôt.
3. Dans GitHub : **Settings → Pages**.
4. Choisis **Deploy from a branch**, puis `main` et `/ (root)`.
5. Enregistre : GitHub Pages publiera automatiquement `index.html`.

## Personnalisation

- Logo : `assets/logo.png`
- Couleurs et design : `assets/style.css`
- Pages : `index.html`, `histoire.html`, `membres.html`, `reglement.html`, `effectif.html`
