# 41st Légion d'Elite — DA verte

Version GitHub Pages avec une direction artistique sombre/verte inspirée de la structure du site Escouade Omega fourni comme référence.

Logo utilisateur intégré : `assets/logo.png`.

Pages : Accueil, Présentation, Histoire, Unités, Grades, Règlement, Recrutement.

Les informations publiques du Google Site ont été utilisées pour le nom, le 9ème Corps d'Assaut et la présentation de la communauté. Les sections qui nécessitent des données privées/officielles sont laissées faciles à compléter.


### Fond vidéo
La page d'accueil utilise `assets/space-bg.mp4` comme fond vidéo. Remplace ce fichier par une autre vidéo MP4 si besoin (même nom).


### Règlement
La page `reglement.html` a été refondue avec une présentation dossier/HUD, sommaire cliquable et sections d'articles. Le texte présent est une base éditoriale à remplacer par le règlement officiel si nécessaire.
