# Escouade Omega — version verte

Version enrichie pour GitHub Pages, inspirée de la structure et de l'ambiance du site de référence.

## Installation
1. Mets tous les fichiers à la racine de ton dépôt GitHub.
2. Va dans Settings → Pages.
3. Choisis Deploy from a branch → main → / (root).
4. Enregistre.

Le logo fourni par l'utilisateur se trouve dans `assets/logo.png`.
